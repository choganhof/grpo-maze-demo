# GRPO Maze Learning Explorer

A React and Vite educational demonstration of GRPO training a CNN to navigate 5×5 mazes. Mode 1 provides checkpoint playback, recorded CNN action probabilities and changes, greedy trajectories, and a training-success graph. Mode 2 remains an introductory placeholder; maze animation and playback are not implemented for it.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (by default, <http://localhost:5173>).

## Build

```sh
npm run build
```
